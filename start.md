# Проектирование Universal AI Knowledge Infrastructure

Спроектировать независимую универсальную инфраструктуру памяти и знаний для AI-агентов.

## Цель

Создать централизованную систему хранения знаний, доступную из любых AI-инструментов: Claude Code, Cursor, Codex, bb и будущих агентов.

Система не должна зависеть от конкретного AI-провайдера или IDE.

## Архитектура

1. **Knowledge Storage**
   - PostgreSQL в Docker.
   - pgvector для семантического поиска.
   - PostgreSQL Full Text Search.
   - Persistent volumes.
   - Backup и восстановление.

2. **Knowledge Service**
   - Go.
   - REST API.
   - Авторизация и разграничение доступа.
   - Управление документами, знаниями, решениями и проектами.
   - Поиск и формирование контекста.

3. **Agent Integration**
   - MCP Server.
   - Универсальные инструменты чтения и записи знаний.
   - Автоматическое получение контекста.
   - Сохранение результатов работы агентов.
   - Адаптеры для разных AI-инструментов.

4. **Agent Orchestration**
   - bb как управляющий слой.
   - Отдельные профили Personal / Work.
   - Раздельные аккаунты, конфигурации и прокси.
   - Интеграция с Knowledge Service.

5. **User Interface**
   - Obsidian как дополнительный интерфейс.
   - Возможность создания собственного Web UI.

## Требования

- Provider-independent.
- Local-first.
- Docker-based deployment.
- Personal / Work / Shared isolation.
- Единый источник знаний.
- Независимость от bb.
- Независимость от Obsidian.
- Экспортируемость данных.
- История изменений.
- Контроль качества записей.
- Безопасное хранение credentials.
- Возможность добавления новых AI-агентов без изменения ядра.

## Принципы разработки

Не создавать монолит.
Разделить Storage, Knowledge API, MCP и Agent Adapters.
Не давать агентам прямой доступ к БД.
Не начинать с embeddings и сложной RAG-системы до появления реальной необходимости.
Сначала определить модель данных, API-контракты и права доступа.

## Результат

Подготовить архитектуру, схему компонентов, структуру репозитория, модель данных, API-контракты, Docker Compose и пошаговый план MVP.
